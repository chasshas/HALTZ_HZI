# HALTZ default font for the GPU text layer (docs/gpu-protocol-v1.md section 3).
# 256 glyphs of 8 x 8 pixels. '#' = pixel on, '.' = off. The left column is bit 7.
# Each glyph: a header line "0xNN name", then exactly 8 rows of 8 characters.
# Glyphs that are not listed are blank. Between glyphs, blank lines and lines starting with
# "# " (hash, space) are comments.
# After editing, run: python3 tools/gen_gpu_tables.py   (rewrites src/gpu_tables.c)
#
# Layout of the ASCII glyphs: capitals and digits use columns 1-5 and rows 0-6, lower case
# has its x-height on rows 2-6, descenders reach row 7. Column 0 and columns 6-7 stay empty,
# so neighbouring characters never touch. 0x80-0x92: box drawing and blocks (names in gpu.h).
